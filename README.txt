Drop your own images into this folder using these exact names and the site will pick them up automatically:

  logo.jpeg   -> the spa's logo, used in the header and footer
  hero.jpeg   -> full-width background photo for the Home/Hero section
  about.jpeg  -> photo for the About section
  image1.jpeg ... image30.jpeg -> the 30 gallery photos

Recommended sizes:
  logo.jpeg    : a clean, high-resolution version of the logo. Note: JPEG does not support
                 a transparent background, so it will show as a small white/solid rectangle
                 behind the logo wherever it sits over a photo or dark background (e.g. the
                 header before you scroll, and the footer). If you're able to send a PNG
                 with a transparent background instead, it will blend in seamlessly — just
                 name it logo.png and let Claude know so the file reference can be updated.
  hero.jpeg    : at least 1920x1080px, landscape, well-exposed (a dark overlay is applied automatically for text legibility)
  about.jpeg   : at least 1000x1200px, portrait or square works best
  gallery images: at least 800x800px, square-ish crops look cleanest in the grid
